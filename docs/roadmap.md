# Roadmap

## Alpha release gates

- Complete the native manual release checklist on Apple Silicon macOS 26.
- Enable private vulnerability reporting and require passing CI on pull requests.
- Review AI classification on a synthetic evaluation set; document limitations.

## Starter contributions

- Improve keyboard navigation and VoiceOver labels in the notch UI.
- Add synthetic examples of ambiguous goal alignment and report regressions.
- Improve troubleshooting for unavailable window titles and model timeouts.

## Later milestones

- Replace deprecated CoreGraphics capture with ScreenCaptureKit.
- Recover failed final checkpoints across process restarts without storing raw OCR.
- Standalone signed and notarized Mac distribution with stable permission identity.
- Optional scheduled daily local reports and configurable exclusions/retention.
- Validate additional hardware/macOS versions before expanding support claims.
