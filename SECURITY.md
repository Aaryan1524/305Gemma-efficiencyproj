# Security

The alpha tracks potentially sensitive screen activity. See [privacy](docs/privacy.md).
Only the current development branch receives fixes; there is no security response SLA.

Use [GitHub private vulnerability reporting](https://github.com/Aaryan1524/FocusLedger/security/advisories/new) for security reports. If the button is unavailable,
request a private reporting channel in a public issue without revealing the
vulnerability, personal data, or reproduction details. Do not post sensitive data.
Include affected revision, macOS/Python versions, impact, and a minimal synthetic
reproduction in the private report.

Private vulnerability reporting was enabled and verified for the alpha release.
