# Code of conduct

Be respectful, constructive, and patient. Welcome contributors with different
backgrounds and experience. Critique ideas and code without personal attacks.
Harassment, discrimination, threats, and publishing another person's private
information are unacceptable in issues, pull requests, or other project spaces.

Maintainers may edit or remove harmful content, close discussions, or restrict
participation. Report concerns through an available private GitHub reporting
channel; do not repeat private information publicly. Maintainers review reports
in context and handle them as privately as practicable. No response SLA is promised.
